Escape from the Maze: A Turn-Based Simulation Game Using Classical Data Structures


This project requires you to implement a simulation of a turn-based multi-agent maze escape game. Agents traverse a maze filled with obstacles, power-ups, traps, and moving corridors. 
You will create the game engine, maze structure, agent behavior, and movement logic, as well as collect metrics such as turn count, path length, backtracking frequency, and game outcomes.
2. Learning Outcomes
Through this project, you will:
• Apply foundational data structures in a simulation scenario.
• Implement stack-based history, queue-based control flow, and circular rotation. • Model turn-based logic, player states, and environment updates.
• Develop modular, structured, and documented code.
• Log simulation output and report meaningful performance metrics.
3. Core Data Structures
• Queue: To manage the agents’ turns in round-robin fashion.
• Stack: To record each agent’s move history for backtracking or undoing moves.
• Circular Linked List: To represent rotating maze corridors.
• Array or Singly Linked List: For representing the maze grid and player registry.
